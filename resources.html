Resources

1. Quarterly Census of Employment and Wages

Average weekly wage in California counties. Different CSV for time periods, get rid of redundant data in CSV by filtering ownership and NAICS level to 0. File Name: Avg_Wage_County_2004_2025.csv

2. Personal Income by County

Personal income change by year for each county, Shows the whole U.S but we can just filter for California. File Name: CAINC1_CA_1969_2024

3. County Personal Income Summary

Personal income amount for each county. Gives total amount for the whole county income it seems. We can just find the average personal income amount by dividing by what the total population of the county was that year. File Name: CAINC1_CA_1969_2024

4. California Counties - Estimate of Median Household Incomes

Median household income for each county. Each county has its own graph so it will take some time to organize the data from this source. File Name: County_Median_Household_Income

5. California Average Listing Price

Average Listing price for each county in California. They do it per month but we can add up each month to get the yearly listing price. File Name: Median_Average_Listing_House_Price

6. House Price Change Count

Tracks the same houses in a county and sees how the price of the house changes yearly. They use an index rather than a dollar amount. Includes only 55 out of 58 counties. File Name: House_Price_Change_Coun

7. Median Price of Single Homes

Median price of single family homes in each county in California. Need an account to access data. FIle Name: MedianPricesofExistingHomes

8. HPI (House Price Index)

House Price index that shows how household price has changed year by year with percentages for each county in California yearly. File Name: hpi_CA_County

9. House Values based on Zillow

The values of Houses based on Zillow's Home Value Index. File Name: Zillow_County_house.csv

10. Census Data API Discovery Tool

contains links to API Census data, can be used to find social, economic, demographic, and housing data, such as median household income data.

11. BEA API Sign Up

signup page for Bureau of Economic Analysis API, can be used to find detailed data on per capita personal income and total personal income.

12. California Datasets / California Datasets for Housing

page that contains thousands of datasets of information published by California state departments and organizations. Can be used to find detailed information on housing, development, and income (second link)

13. Huduser API Sign Up

signup page for API that tracks income limits for federal housing programs and Fair Market Rent (40th Percentile Gross Rent)

14. FRED API Sign Up / FRED Non-API Sign Up

signup page for API that contains national, state, metropolitan statistical area (MSA), and county-level single-family home values. Non-API version for reference (second link)

15. California Employment Datasets

datasets covering employment information and quarterly census of employment and wages within the state of California. Can be used to pull wage and employment data, such as the average weekly wage per county.

16. Population and Housing Estimates Datasheet

datasheet that contains the E-5 population and housing estimates, the official January 1 baseline estimates for population, total housing units, and average household size (along with other info) for California counties.
