# California housing and income map

HTML/CSS/JavaScript group project comparing housing and income changes across California counties.

The current map page is `main-page.html`. Serve this folder with `python3 -m http.server 8000`, then open `http://localhost:8000/main-page.html`.

Prepared county data and source definitions, coverage, rebuild instructions, and integration example are documented in [docs/data.md](docs/data.md). The prepared JSON is not yet connected to the page.
